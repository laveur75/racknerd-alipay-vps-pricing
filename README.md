## 选哪一档：看你要跑什么

768M 那一档的瓶颈在内存，不限在硬盘。装个 Alpine 或者最小化 Debian 跑代理、跑定时任务、做监控探针，768MB 很宽裕。但你要装宝塔、1Panel 这类面板，面板本身加上 MySQL、Nginx、PHP 就要吃掉 400MB 以上，再挂个 WordPress，剩下的内存会在流量稍微上来时被 OOM 杀掉进程。

所以建站场景直接从 1G 那档起，25GB 硬盘也更从容，系统、面板、站点文件、日志加起来，12GB 用不了几个月就紧张。

想跑 AI 类一键应用的话，官方给的门槛很明确：n8n 和 Coolify 从 2GB 内存起比较舒服，对应 $27.88 的 2.5G 档；Ollama、LibreChat、AnythingLLM、Hermes Agent 至少要 4GB，对应 $43.39 的 4G 档；OpenClaw 要求 8GB 起，这张表里没有，得去看官网其他档位。拿 $10.88 的机器硬跑这些，装完就卡死。

机房方面，中文资料普遍建议中国用户选洛杉矶 DC-02，说这条线接了中国电信 CN2 和联通的优化线路；其次是圣何塞和西雅图。其他可选节点分布在多个美国机房，以及加拿大、荷兰、法国。

## 这几类人不适合买

**需要发票或对公转账的**：RackNerd 是海外商家，收款走支付宝跨境通道，开不出国内增值税发票，报销走不通。

**需要 SLA 兜底的生产环境**：官方 specials 页面写得很清楚，这些特价机是 unmanaged KVM VPS，只有 root 权限和 ctrl 面板，系统里的东西全得自己弄，出问题提工单，没有“帮你排查业务故障”这一项。

**手里只有微信支付的**：付款方式里没有微信，这条路走不通。

**要长期跑满大带宽的**：1Gbps 端口和 10TB 月流量看着宽裕，但这是给轻量业务准备的促销机型，不是给视频站、下载站这种持续高负载场景设计的。这类需求该去看独立服务器或专门的流媒体方案。

**要求国内低延迟的**：洛杉矶 DC-02 有中国方向优化，但那是“优化”，不是三网回程 GIA。对延迟极度敏感的业务，还是得为线路单独付钱。
